# 数直線メーカー（number-line-maker）

算数の問題づくりで使う**数直線**をブラウザで組み立て、**背景透過PNG**として書き出す教師用ツール。

> **位置づけ**: このアプリは**ワークシートを作る場所ではなく、素材（パーツ）を作る場所**です。
> 用紙への割り付け・印刷は、別のワークシート作成工程（HTML → Chrome headless → PDF）が受け持ちます。

- 要件定義（正本）: Obsidian `0003_projects/数直線作成アプリ/01_要件定義.md`
- 技術: 素の HTML + JavaScript（ES Modules）。**ビルド不要・依存ライブラリなし**
- 描画: SVG → `<canvas>` → PNG

## できること

画面は縦一列の **「基本の数値バー → プレビュー → 書き出しボタン」**（2026-10-01 改修）。

- 基本バーの数値を変えると、すぐ下のプレビューが即座に変わる
- ★**目盛りをクリックすると、その目盛りのすぐそばに小さな編集窓**が出る
  （□・文字・分数・ふりがな・引き出し矢印・縦の破線を**その場で**変える。設定パネルとの視線往復をなくした）
- 細かい設定（目盛りの長さ・両端・単位・色・用紙）は「詳しい設定」を押したときだけ出る
- 上部のチップ（0〜10 / 大きい数□ / 引き出し□ / 比例数直線 など）から型で始められる

### 画面（2026-10-02 刷新）

制作ソフトらしい落ち着いた枠の中央に、白いアートボードを置く形。暗い画面が既定で、右上の ◐ で明るい画面にできる。

- **上（アプリバー）**: 作品名・新規・ライブラリ・複製・保存・書き出し・詳しい設定
- **その下（オプションバー）**: これだけで1本できる（形／はじめ・おわり・目盛りの数・幅／数の書き方／数字を出すところ／向き）
- **左**: テンプレート（見本つき。選ぶだけ）　**中央**: アートボード　**右**: 詳しい設定（開いたときだけ）
- **目盛りをクリック**すると編集窓が出る。**編集窓は必ず数直線の外に出す**（被ると次の目盛りが押せないため）

### 数の書き方

| 選ぶもの | 例 |
|---|---|
| ふつう | 1000000 → 100万、100000000 → 1億（1万未満と小数はそのまま） |
| 数字のまま | 1000000 |
| 分数（帯分数） | 0〜2 を 10目盛り → 1/5, 2/5 … 1, 1と1/5 … |
| 分数（仮分数） | 同上 → … 1, 6/5, 7/5 … |

分数は **はじめ・おわりを整数で入れ、目盛りの数を決めるだけ**（分母は自動）。約分は「詳しい設定」で選べる。
割り切れない数（0〜1 を3等分など）を入れると、分数にするよう案内が出る。

### 重なりを必ず解く

1. □ が隣の数字・隣の□に当たるときは、**□を少し縮めて収める**（既定の幅の65%まで）
2. それでも当たる数字は出さない

### 数の入れ方（2026-10-02 改修）

- **教科書どおりの数をそのまま打つ**。`1000000` と打てば **100万**、`100000000` と打てば **1億** と出る
  （「万・億で書く」のチェックを外すと `1000000` のまま）
- **数字どうし・数字と□は重ならない**。「数字を出すところ」が **おまかせ** なら重ならない間隔を自動で選び、
  □や文字を置いた目盛りの隣の数字は自動で引っ込む。**両はしだけ**／n目盛りごと／出さない も選べる
- **「おわりの数」は勝手に変わらない**。はじめの数・目盛りの数を変えたら、1目盛りの値のほうを計算し直す
- 入力欄の下に「1目盛り = 10万 ／ 0 から 100万 まで」と常に出るので、打ち間違いに気づける

### 目盛り

- **等間隔が基本**。「はじめの数・おわりの数・目盛りの数」を入れると 1目盛りの値が決まる
- **目盛りは既定で「上に伸びる」**（教科書の数直線の形）。下・上下にも変えられる
- 目盛りの長さを**3階層**（最小 / n個ごと / m個ごと）で設定。**3つまとめて伸縮**もできる
- n・m は可変（既定 5 と 10）。線種は実線／破線、向きは上・下・上下

### ラベル

- 数字の自動振り（何目盛りごとに出すか）
- ★**数字の前後に文字を付けられる**（「50」＋「万」＝**50万**）。「0 には付けない」も指定できる
- **目盛りを1つずつクリックして個別に編集**できる
  - 自動（数字）／なし／文字／**分数（縦分数・帯分数）**／**□（穴埋め・幅と高さを調整）**
  - **ふりがな（ルビ）**を付けられる（`x` に「エックス」など）
  - **その目盛りの線だけ消す**こともできる
  - ★**引き出し**: ラベルを線から離して置き、**矢印で目盛りをさす**（教科書の「□↓」の形）
  - ★**出す位置を目盛りごとに上下指定できる** → **数字は線の上・記号は線の下**という形が作れる
  - ★**「記号で問う」ボタン1回**で、数字の反対側に ア・イ・ウ ＋上向き矢印が置かれる

> 「0・1・3 だけラベルがある図」は、目盛りを 0,1,2,3 と等間隔に並べ、
> 2 のラベルと目盛り線を消して作ります（`1→3` の幅は `0→1` の2倍＝算数的に正しい形）。

### 複数の数直線（比例数直線）

- 数直線を**何本でも**増減できる
- **左端（0）を縦の実線でつなぐ**
- 指定した目盛り位置で**軸どうしを縦の破線でつなぐ**
- 各軸の右端に**単位**を括弧付きで置ける（`(kg)` `(m)`）
- 「目盛りを全部そろえる」で、全軸の目盛り幅・目盛り数を同期

### 書き出し

- **背景透過PNG**（150 / 300 / 600 dpi）
- **SVG**（ワークシートがHTML→PDFなので、貼るならこちらが荒れない）
- 余白（上右下左）を mm で指定
- 出力の大きさを mm と px で常時表示

### 用紙サイズ感

- A4縦 / A4横 / B5縦 / B5横 に**実寸で置いた姿**を表示し、本文幅に対する占有率(%)を出す
- ⚠️ **あくまで参考表示**。用紙に合わせる機能・警告・自動縮小は意図的に作っていない

### 作品ライブラリ

- 名前・単元名を付けて保存し、**サムネイル付きの一覧**から呼び戻して編集
- 容量: サムネイルは **JPEG で1件約6KB**。localStorage の上限5MBに対し **400件程度まで**入る（ライブラリ画面に使用量を表示）
- **複製して数字だけ変える**（似た問題の量産がこのアプリの主目的）
- 編集中の状態は自動保存（リロードしても消えない）
- ライブラリ全体を JSON で書き出し／読み込み（端末の引っ越し・バックアップ用）

## 設計のメモ

### 保存は localStorage のみ

- 🚫 **Obsidian vault にこのアプリの JSON を置かない**（本人方針）
- 🔭 将来は**専用DB**へ移す可能性がある
- ★ そのため **`js/storage.js` に保存の実装を閉じ込め、全関数を async にしてある**。
  DB へ移るときは **このファイルだけを差し替えれば済む**

### 透過の担保

`toPNGBlob()` では canvas に**背景を一切塗らず** `drawImage` するだけにしている。
`tools/selftest.html` が書き出したPNGの**四隅のアルファが0であること**を毎回確認する。

### フォント

`UD Digi Kyokasho`（Windows 10+ 標準）→ `游教科書体`（Mac）の順で指定。

> SVG を `<img>` 経由でラスタライズすると **Webフォント（@font-face）は読めない**が、
> **OS 搭載フォントは使える**。そのため教科書体をフォント名で指定している。
> Mac と学校 Windows で字形がわずかに変わる点は許容している（数字中心のため）。

### 分数・ルビ

MathJax 等は使わず、`<text>` と `<line>` を自前で配置して組んでいる（外部リソースを持ち込まないため）。

## リンクで作品を渡す

`…/number-line-maker/#import=<作品をbase64urlにしたもの>` を開くと、その作品が**ライブラリに保存される**
（同じ名前・同じ中身なら二重に入れない）。別の端末・別のブラウザへ作品を渡す入口。

## 動作確認

`tools/drive.mjs` は **本物のマウス・キーボード入力**（Chrome DevTools Protocol）で画面を動かす。
`tools/scenario-naive.mjs` は「何も知らない人が、教科書どおりの数を打って2本作り、保存して書き出す」までをなぞる。

```sh
node tools/drive.mjs tools/scenario-naive.mjs /tmp/out   # 途中の画面・PNG・作品データが /tmp/out に出る
node tools/drive.mjs tools/scenario-kinds.mjs /tmp/out   # 整数・小数・分数・2本を作り、手数と重なりを数える
```

押そうとした場所に別の要素が被っていたら（＝人には押せない）テストは失敗になる。

> ★`tools/make3.html` はイベントを直接投げる方式なので「機能が動くか」は分かるが、
> **人が打った数で読める図になるか**は分からなかった。2026-10-02 に本人が作れなかったのはここ。

```sh
python3 -m http.server 8777
# ブラウザで http://localhost:8777/tools/selftest.html

# ヘッドレスでも確認できる
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --virtual-time-budget=8000 --dump-dom \
  "http://localhost:8777/tools/selftest.html" | grep RESULT
```

`?preset=oku3` のように付けると、その型で開く
（`basic10` / `oku1` / `oku2` / `oku3` / `mark` / `decimal` / `ratio2`）。

`tools/make3.html` は **本物の index.html を iframe に読み込み、実際のボタンを押して**
教科書「大きい数」練習⑥の数直線を作る。UIの操作でつまずく箇所を見つけるためのもの。
