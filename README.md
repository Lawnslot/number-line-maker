# 数直線メーカー（number-line-maker）

算数の問題づくりで使う**数直線**をブラウザで組み立て、**背景透過PNG**として書き出す教師用ツール。

> **位置づけ**: このアプリは**ワークシートを作る場所ではなく、素材（パーツ）を作る場所**です。
> 用紙への割り付け・印刷は、別のワークシート作成工程（HTML → Chrome headless → PDF）が受け持ちます。

- 要件定義（正本）: Obsidian `0003_projects/数直線作成アプリ/01_要件定義.md`
- 技術: 素の HTML + JavaScript（ES Modules）。**ビルド不要・依存ライブラリなし**
- 描画: SVG → `<canvas>` → PNG

## できること

### 目盛り

- **等間隔が基本**。目盛りの数と「1目盛りの幅(mm)」で決まり、位置は値に比例する
- 目盛りの長さを**3階層**（最小 / n個ごと / m個ごと）で設定。**3つまとめて伸縮**もできる
- n・m は可変（既定 5 と 10）。線種は実線／破線、向きは上・下・上下

### ラベル

- 数字の自動振り（開始値・1目盛りの値・何目盛りごとに出すか）
- **目盛りを1つずつクリックして個別に編集**できる
  - 自動（数字）／なし／文字／**分数（縦分数・帯分数）**／**□（穴埋め・幅と高さを調整）**
  - **ふりがな（ルビ）**を付けられる（`x` に「エックス」など）
  - **その目盛りの線だけ消す**こともできる

> 「0・1・3 だけラベルがある図」は、目盛りを 0,1,2,3 と等間隔に並べ、
> 2 のラベルと目盛り線を消して作ります（`1→3` の幅は `0→1` の2倍＝算数的に正しい形）。

### 複数の数直線（比例数直線）

- 数直線を**何本でも**増減できる
- **左端（0）を縦の実線でつなぐ**
- 指定した目盛り位置で**軸どうしを縦の破線でつなぐ**
- 各軸の右端に**単位**を括弧付きで置ける（`(kg)` `(m)`）
- 「目盛りを全部そろえる」で、全軸の目盛り幅・目盛り数を同期

### 書き出し

- **背景透過PNG**（150 / 300 / 600 dpi）
- **SVG**（ワークシートがHTML→PDFなので、貼るならこちらが荒れない）
- 余白（上右下左）を mm で指定
- 出力の大きさを mm と px で常時表示

### 用紙サイズ感

- A4縦 / A4横 / B5縦 / B5横 に**実寸で置いた姿**を表示し、本文幅に対する占有率(%)を出す
- ⚠️ **あくまで参考表示**。用紙に合わせる機能・警告・自動縮小は意図的に作っていない

### 作品ライブラリ

- 名前・単元名を付けて保存し、**サムネイル付きの一覧**から呼び戻して編集
- **複製して数字だけ変える**（似た問題の量産がこのアプリの主目的）
- 編集中の状態は自動保存（リロードしても消えない）
- ライブラリ全体を JSON で書き出し／読み込み（端末の引っ越し・バックアップ用）

## 設計のメモ

### 保存は localStorage のみ

- 🚫 **Obsidian vault にこのアプリの JSON を置かない**（本人方針）
- 🔭 将来は**専用DB**へ移す可能性がある
- ★ そのため **`js/storage.js` に保存の実装を閉じ込め、全関数を async にしてある**。
  DB へ移るときは **このファイルだけを差し替えれば済む**

### 透過の担保

`toPNGBlob()` では canvas に**背景を一切塗らず** `drawImage` するだけにしている。
`tools/selftest.html` が書き出したPNGの**四隅のアルファが0であること**を毎回確認する。

### フォント

`UD Digi Kyokasho`（Windows 10+ 標準）→ `游教科書体`（Mac）の順で指定。

> SVG を `<img>` 経由でラスタライズすると **Webフォント（@font-face）は読めない**が、
> **OS 搭載フォントは使える**。そのため教科書体をフォント名で指定している。
> Mac と学校 Windows で字形がわずかに変わる点は許容している（数字中心のため）。

### 分数・ルビ

MathJax 等は使わず、`<text>` と `<line>` を自前で配置して組んでいる（外部リソースを持ち込まないため）。

## 動作確認

```sh
python3 -m http.server 8777
# ブラウザで http://localhost:8777/tools/selftest.html

# ヘッドレスでも確認できる
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --virtual-time-budget=8000 --dump-dom \
  "http://localhost:8777/tools/selftest.html" | grep RESULT
```

`?preset=ratio2` のように付けると、その型で開く（`basic10` / `basic100` / `decimal` / `ratio2`）。

## 対応ブラウザ

Chrome（PC）推奨。ES Modules・`<dialog>`・`canvas.toBlob` を使用。
